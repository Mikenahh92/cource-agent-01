# course-agent-01 — Final Assignment Repo

Target repo for the AI Agent Development workshop final assignment.

**The task is in the issues** — one for Python, one for TypeScript. Pick the language you (or your agent) prefer.

| Project | Issue |
|---|---|
| `python/` | Python assignment issue |
| `typescript/` | TypeScript assignment issue |

Build an agent that retrieves the issue, fixes the code, and opens a pull request.

Rules:
- No direct commits to `main` — pull requests only.
- Name your branch `fix/<your-name>`.
